## 🧩 About

**BeamNG Companion** is a curated list of BeamNG open-source tools:

- **Overlays** — on-screen helpers, layout notes, vehicle stats viewer, scene switcher
- **Quality-of-Life Helpers** — config catalog, garage organizer, overlay notes
- **Research Notes** — physics study layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Scene Switcher — jump to any saved scenario
- Vehicle Stats Overlay — visualize speed, torque, damage
- Replay Notes — record and review driving runs
- Simulation Speed — adjust physics playback for study (0.1x to 5x)

### Wallhack
- Vehicle Catalog — browse configs, colors, parts
- Custom Tuning Notes — organize vehicle setups
- Camera Overlay Notes — improved free-camera visibility

### Aimbot
- Scenario Notes — segment study on any map
- Gravity Control — manually adjust gravity for testing
- Input Buffer Notes — chain complex maneuvers in the editor
